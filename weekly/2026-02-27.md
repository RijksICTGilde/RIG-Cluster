# ZAD Update — 6 t/m 27 februari 2026

## Nieuw

- **Authorization Wall** — Een authenticatie-proxy voor applicaties die zelf geen login hebben. Zet `authorization-wall` aan in je project YAML en gebruikers moeten eerst inloggen via Keycloak voordat ze bij je app kunnen; vooral (alleen) bedoeld
voor statisch websites.
- **Container images uploaden** — Docker images uploaden naar de RCR registry (rcr.rijksapps.nl) via het portaal. Handig als je achter een VPN zit en geen directe toegang hebt tot Quay. Dit is een tijdelijke oplossing voor 'private' images.
- **Componenten toevoegen aan bestaande projecten** — Via de API kun je nu componenten toevoegen en toewijzen aan een bestaand project, zonder het hele project opnieuw aan te maken.
- **Slimmer omgaan met resources** — ZAD kan nu het daadwerkelijke geheugengebruik van je componenten opvragen en op basis daarvan aanbevelingen doen. Zo kun je resources afstemmen op wat je echt nodig hebt in plaats van wat je ooit hebt aangevraagd.

## Verbeterd

- **Zero-downtime rolling updates** — Deployments worden nu zonder 503-errors bijgewerkt dankzij een `preStop` hook die het Kubernetes race-condition probleem oplost.
- **Stabiliteit Operations Manager** — Crashes door geheugengebrek zijn opgelost. Monitoring-taken draaien niet meer dubbel en worden netjes opgeruimd.
- **PostgreSQL verbindingen** — Van 100 naar 200 gelijktijdige verbindingen, dit is tijdelijk en een werkende
- oplossing voor pooling wordt onderzocht.
- **SSO-Rijk migratie** — Directe koppeling met SSO-Rijk, zonder tussenstap via Digilab.
- **ArgoCD refresh performance** — Onderzoek en aanpak van trage refreshes (2+ minuten) na het aanmaken van projecten.

## In ontwikkeling

- **Dynamische formulieren** — De basis is gelegd voor slimmere formulieren die zich aanpassen aan je projectconfiguratie. Denk aan wizards en validatie in het Nederlands.
- **PgBouncer connection pooling** — Ontwerp klaar om database-verbindingen efficienter te delen tussen applicaties.
- **Forgejo op ODCN met Keycloak SSO** — In-cluster git server met OIDC login via Keycloak.
- **Invites als service** — Het invite-systeem wordt omgebouwd naar een volwaardige service, instelbaar via de wizard.
- **Wizard stap voor registry configuratie** — Private registries instellen via de wizard in plaats van handmatig YAML bewerken.
- **Custom sign-in pagina voor Authorization Wall** — Inlogpagina in Rijkshuisstijl in plaats van de standaard oauth2-proxy pagina.
