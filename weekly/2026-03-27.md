# ZAD Update - 10 t/m 27 maart 2026

## Nieuw

- **Security Headers (internet.nl compliance)** - ZAD stuurt nu HSTS, Content-Security-Policy, X-Frame-Options, Referrer-Policy en Permissions-Policy mee op alle responses. Inclusief `security.txt` endpoint. Dit brengt ons in lijn met de internet.nl standaarden.

- **Admin Usage Page** - Nieuw admin-dashboard voor resource-gebruik en kosten per project, gebaseerd op Grafana Mimir billing data. Geeft inzicht in geheugen- en CPU-verbruik over alle deployments.

- **Schema Migratie v2 naar v2.1** - Root-component definitie verhuisd van component-level (`root: true`) naar deployment-level (`root-component: "naam"`). Automatische migratie met opschoning van wizard-artefacten.

- **ACME Issuer Scoping per Deployment** - Let's Encrypt issuers en network policies krijgen nu een deployment-suffix. Dit lost ArgoCD SharedResourceWarnings op bij meerdere deployments in hetzelfde namespace.

## Verbeterd

- **Resource Auto-Tuning gehardend** - Leest nu direct uit git i.p.v. de in-memory cache, waardoor stale data geen YAML-velden meer overschrijft. OOM-detectie met sliding scale (2-3x bump afhankelijk van geheugengrootte), max memory cap van 4Gi, en deduplicatie van no-op changes.

- **Async Prometheus/Grafana Connector** - Overgestapt van synchrone `requests` naar async `httpx`. Metriek-queries per component draaien nu parallel via ThreadPoolExecutor. Minder wachttijd op dashboards.

- **ArgoCD UI Responsiveness** - Fix voor trage ArgoCD interface bij grote aantallen applicaties door resource limits optimalisatie.

- **Domain Wizard View** - Fix voor rendering van custom domain configuratie in de wizard.

- **Favicon** - ZAD heeft nu een eigen favicon.

## Bugfixes

- Auto-tune stripte stilletjes niet-gerelateerde YAML-velden bij het terugschrijven - opgelost
- Resource leak en ongebruikte import in resource tuning service
- Ontbrekende async/await in diverse codepaden
- Root component en schema validatieproblemen opgelost
- Component image field scope verduidelijkt

## In Ontwikkeling

- **Backup & Restore** - Restore wizard met stap-voor-stap review, pre-create PVCs, en service-selectie. Bijna klaar voor merge.

- **Job Runner** - Ondersteuning voor het draaien van eenmalige jobs (database migraties, data imports) binnen een deployment. Inclusief YAML-injectie beveiliging en E2E tests.

- **Stop/Start Deployments** - Deployments kunnen straks gepauzeerd en hervat worden via een replicas-veld. Inclusief bare domain support.

- **User Management** - Vervanging van de in-memory allowlist door een ZAD users tabel. Keycloak SSO logout, admin auto-detect, en invite management.

- **Security Hardening** - Audit trail, API key management per project, en notificatie-systeem.

- **Clone Components** - Mogelijkheid om componenten van een bestaand deployment te klonen naar een nieuw deployment via `cloneComponentsFrom` in de API.

## Onder de Motorkap

- Productie deployment: error log PVC, geheugen/CPU limits geoptimaliseerd
- Grafana billing datasource toegevoegd aan cluster configuratie (admin only)
- Uitgebreide testdekking: security headers, auto-tune field preservation, schema migratie, Grafana batch queries, Prometheus parallel queries
