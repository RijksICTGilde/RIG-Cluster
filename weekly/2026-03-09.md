# ZAD Update — 28 februari t/m 9 maart 2026

## Nieuw

- **Async Task System (V2 API)** — Alle zware operaties (project aanmaken, deployments, backups) draaien nu async met real-time progress tracking. Clients krijgen direct een task ID terug en kunnen de voortgang volgen via `/api/v2/tasks/{task_id}`. Dit voorkomt timeouts bij grote operaties.

- **Detail Page Inline Editing** — Projectdetails kunnen nu direct in-place bewerkt worden zonder de pagina te verlaten. Componenten, services, environment variabelen, en meer zijn direct editabel met live validatie en foutafhandeling.

- **Backup & Restore Wizard** — Volledige wizard voor het back-uppen en terugzetten van deployments:
  - Kies welke services je wilt back-uppen (database, storage)
  - Optie om naar een nieuwe deployment te terugzetten
  - Ondersteuning voor v1 en v2 project files
  - Pre-create PVCs voordat infrastructure wordt ingezet

- **CodeMirror 6 Syntax Highlighting** — KV editor (Key-Value configuratie) krijgt nu syntax highlighting voor beter leesbare en veiligere configuraties. Verkeerd ingetypte JSON wordt direct zichtbaar.

- **Database Migrations (Alembic)** — Migraties naar een professioneel systeem i.p.v. raw SQL. Dit maakt database-upgrades veiliger en herhalbaar.

- **OpenTelemetry & Jaeger Tracing** — Gedistribueerde tracing voor het volgen van requests door het hele systeem. Handiger debuggen van bottlenecks en latency-issues. SigNoz stack vervangen door Jaeger all-in-one.

- **Custom Domain Support** — Projects kunnen nu custom domeinen gebruiken via een `domain_format` field. Defers-to pattern voor intelligente domain-nesting.

- **HTMX Lazy-Loading Metrics** — Deployment metrics (CPU, geheugen) worden pas geladen als je ernaartoe scrollt. Minder laadtijd en bandbreedte.

- **E2E Browser Tests (Playwright)** — Volledige Playwright test suite voor de web UI. Testen of wizards, formulieren, en flows correct functioneren in echte browsers.

- **Dev Server Sandbox Setup Guide** — Gids voor het lokaal opzetten van een volledig Kubernetes cluster (Kind) met alle services voor development.

## Verbeterd

- **Backup Wizard Enhancements** — Deployments kunnen nu in het backup-selectie-scherm bewerkt worden (resources, environment vars). Leeg service-velden worden automatisch gefilterd.

- **Project Completion Handling** — Als iets deels faalt, geeft het systeem een betere foutmelding in plaats van het hele project als mislukt te markeren.

- **Cluster Validation** — Voordat je een project inzet, valideert ZAD nu dat het cluster beschikbaar is en correct geconfigureerd.

- **Service Detection v1/v2** — Beter herkennen van services in zowel oude (v1) als nieuwe (v2) project file formaten.

- **RBAC voor Deployment Monitoring** — Finer-grained permissions voor wie deployment monitoring mag zien.

- **Documentatie Opschoning** — Verouderde docs gearchiveerd, CLAUDE.md bijgewerkt, kennisbase gestroomlijnd.

## In Ontwikkeling

- **Database Reconciliation & Cleanup** — Automatische opschoning van orphaned databases en buckets die niet meer in project files voorkomen. Dry-run modus beschikbaar via admin API.

- **Multi-Cluster Task Federation** — Tasks kunnen nu aan andere clusters worden gedelegeerd. De foundation voor multi-cluster setups.

- **E2E Sandbox Testing met Multi-Session Coördinatie** — Testinfrastructuur voor het tegelijkertijd draaien van meerdere test-sessies zonder botsingen.

- **PgBouncer Connection Pooling** — Database-verbindingen worden slimmer gedeeld. Dit lost het 1Gi disk-probleem op via betere WAL management.

## Onder de Motorkap

- **Alembic Database Migrations** — Ervan afgegaan naar raw CREATE TABLE calls. Veiliger, herhalbaar, versiebeheerd.

- **Task Progress Tracking Standardisatie** — Alle async operations volgen dezelfde progress format. Consistent in API, web UI, en logs.

- **Jaeger All-in-One** — Vervanging van SigNoz stack. Makkelijker deployment, minder resources nodig voor tracing.

- **Service Dependency Enforcer** — Validatie dat services correct geconfigureerd zijn voordat deployment plaatsvindt.

- **Async Setup Fixes** — Diverse fixes voor race conditions, event loop management, en connection pooling in async context.

**Volgende focus:** PgBouncer connection pooling afronden, database reconciliation naar production, E2E tests uitbreiden, multi-cluster federation testen.
