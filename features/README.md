# features/

Wat een feature is en hoe hij werkt, een document per feature. De bestanden staan plat in deze map; deze index deelt ze in per thema. Een nieuw document hoort er een regel bij te krijgen.

Ontwerpen voor werk dat nog niet gebouwd is, staan niet hier: die horen een kaartje op het ZAD-bord te worden. De oude ontwerpen uit `features/futures/` staan in RIG-Cluster-Legacy.
