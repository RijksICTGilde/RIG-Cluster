# Fundament-fieldlab 2026

Deze map is alleen voor het Fundament-fieldlab 2026: het registratie-endpoint waarmee een ZAD-installatie op Fundament een eigen domein, een wildcardcertificaat en een Keycloak-client krijgt. Na het fieldlab gaat hij weg.

Alles van het fieldlab staat bewust in deze map, ook wat normaal in `opi/connectors/` hoort, zoals de aanroep van lego. Zo is weghalen een map verwijderen, plus de stappen in [Weghalen na het fieldlab](../../../../features/fundament-registratie.md#weghalen-na-het-fieldlab).
